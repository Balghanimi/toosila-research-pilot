# 📦 Archived Documentation

This folder contains old documentation files that have been superseded by the new organized structure.

## Why Archive?
- Keep git history clean
- Easy rollback if needed
- Reference for old information

## Files to Move Here
The following files in root can be moved here:

### Reports (Old)
- `*_REPORT.md`
- `*_SUMMARY.md`
- `*_FINDINGS.md`

### Guides (Superseded)
- `*_GUIDE.md` (except README)
- `QUICK_*.md`

### One-time Fixes
- `FIX_*.md`
- `*_FIX*.md`

## How to Move (Manual)
```bash
# Move old reports
mv *REPORT*.md docs/archive/
mv *SUMMARY*.md docs/archive/
mv *FIX*.md docs/archive/
```
